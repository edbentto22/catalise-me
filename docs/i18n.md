# Idiomas (pt, en, es)

O site é publicado em português (`/`), inglês (`/en`) e espanhol latino-americano (`/es`). Cada página tem uma única implementação e um dicionário de textos por idioma.

## Onde fica cada coisa

| O quê | Onde |
| --- | --- |
| Textos das páginas | `src/i18n/content/*.ts` (`home`, `about`, `manifesto`, `opera`, `contact`) |
| Textos de interface (menu, rodapé, dock, WhatsApp) | `src/i18n/ui.ts` |
| Rótulos de navegação e idiomas | `src/i18n/config.ts` |
| Layout de cada página | `src/views/*View.astro` |
| Rotas | `src/pages/*.astro`, `src/pages/en/*.astro`, `src/pages/es/*.astro` (só chamam a view com o `locale`) |

Campos com `em`, `strong`, `mark` ou `br` são renderizados com `set:html`; os demais são texto puro.

## Alterar ou acrescentar um texto

1. Edite a chave no dicionário em `pt`, `en` e `es`.
2. Rode `npm run i18n:check` para garantir que os três idiomas têm a mesma estrutura (mesmas chaves e mesmo número de itens nas listas).
3. Rode `npm test` e `npm run build`.

Links internos nas views usam sempre `localizedHref(path, locale)`, para que `/sobre` vire `/en/sobre` e `/es/sobre` automaticamente. O seletor de idioma, `hreflang`, `x-default`, canonical e `og:locale` são gerados pelo `BaseLayout`.

## Nova página

1. Crie o dicionário em `src/i18n/content/` com `pt`, `en` e `es`.
2. Crie a view em `src/views/` recebendo `locale`.
3. Crie os três wrappers em `src/pages/`, `src/pages/en/` e `src/pages/es/`.
